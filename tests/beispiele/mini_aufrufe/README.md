# Aufrufe

Erfundenes Beispielprojekt für die Tests von Daidalos (A07, A07b): Funktionsknoten, `ruft`-Kanten,
Annotationen, Komplexität, Zugriffe auf Accessoren und Typen durch Nachschlagen. Jede Datei nennt
im Kopfkommentar die Fälle, die sie abdeckt. Der Code muss nicht übersetzbar sein; er soll nur
die Auflösung prüfen.
